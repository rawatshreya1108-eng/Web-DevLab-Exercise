 Program 2: Portfolio Website Using Git

* Aim- To create a personal portfolio website and learn how to use basic Git commands.

* Technologies Used-
- HTML
- CSS
- Git

* Git Commands Used-

1. `git init`

Used to start a new Git repository in the project folder.

2. `git add`

Used to add all project files to Git before saving them.

3. `git commit -m " "`

Used to save the changes made in the project with a message.

4. `git log`

Used to see the list of previous commits and their details.

* Project Structure-
- `index.html` – Main page of the website.
- `style.css` – Used to style the website.
- `README.md` – Contains project details.

* Result-
Successfully created a basic personal portfolio website using HTML and CSS. Learned how to start a Git repository, add files, save changes using commits, and view commit history.
