 Program 3: Git Branching

* Aim- The aim of this program was to understand Git branching and learn how to create and manage different branches in a Git repository.

* Introduction-
 The main branch contains the primary version of our project, while another branch can be used to test or develop new changes.

* Commands Used-

1. `git branch` – Displays all the branches available in the repository and shows the current branch.

2. `git branch new-branch` – Creates a new branch named `new-branch` without switching to it.

3. `git switch new-branch` – Switches from the current branch to the newly created branch.

4. `git switch main` – Switches back to the main branch.

5. `git merge new-branch` – Combines the changes from the new branch into the main branch.

* Result-
Successfully learned the concept of Git branching and practiced creating, switching, managing, and merging branches using Git commands. This helped us understand how multiple versions of a project can be managed efficiently by creating branch other than main and editing it, later merging it if needed.
