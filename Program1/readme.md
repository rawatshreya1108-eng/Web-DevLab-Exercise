Program 1 – Terminal Navigation and Folder Management

* Aim: To learn basic Terminal commands and understand how to navigate directories, create folders, and manage files.

* Commands Used and Their Purpose-

1) cd Web-DevLab-Exercise – Navigates into the existing project directory.

2) pwd – Displays the current working directory.

3) mkdir Program1 – Creates a new folder named Program1.

4) cd Program1 – Enters the Program1 directory.

5) mkdir Myporfolio – Creates a portfolio project folder.

6) cd Myporfolio – Navigates into the portfolio folder.

7) mkdir emptyfolder – Creates a subfolder inside Myporfolio.

8) cd .. – Moves back to the parent directory.

9) ls – Lists the files and folders in the current directory.

10) touch readme.md – Creates an empty file named readme.md.

* Final Directory Structure-

   * emptyfolder
  b)readme.md

2) Understood directory paths and folder hierarchy.
